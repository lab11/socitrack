# TotTag logo

The mark is a caregiver and a smaller child, close enough to overlap: what a TotTag measures. It is used
on the documentation site and in the browser tool at app.tottag.net.

| File | Use it on |
| --- | --- |
| `tottag-logo.svg` | Light backgrounds: the mark with the name beside it |
| `tottag-logo-dark.svg` | Dark backgrounds |
| `tottag-logo-reversed.svg` | Coloured backgrounds and photos, such as the documentation's header |
| `tottag-mark.svg`, `-dark`, `-reversed` | The same three, without the name: icons, avatars, small spaces |
| `tottag-favicon.svg` | Browser tabs and bookmarks. Follows the browser's light or dark appearance |

## Colours

| | Light | Dark |
| --- | --- | --- |
| Caregiver (blue) | `#2f6db3` | `#6aa8e0` |
| Child (apricot) | `#f4a259` | `#f4a259` |
| Name | `#2b2620` | `#f3ede5` |

On a coloured background, the caregiver and the name are white.

## Details

- The name is set in [Nunito](https://github.com/googlefonts/nunito) ExtraBold (SIL Open Font License 1.1),
  converted to outlines, so the files need no font installed.
- Everything is plain paths and circles: no masks, filters or embedded fonts, so the files survive any
  tool that imports SVG. The gap between the two circles is cut out of the larger one, so whatever is
  behind the logo shows through it.
- The marks are drawn on a 64 × 64 square. Keep at least a quarter of the mark's height clear around it,
  and do not recolour, stretch or add effects.
